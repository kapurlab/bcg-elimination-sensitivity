# Outputs

Everything here is regenerated by the scripts in `R/`; nothing is edited by
hand. Figures are PNG at 200 dpi; tables are CSV.

## Figures used in the memo

| File | Content |
| --- | --- |
| `figs/fig14_memo_scenarios.png` | Scenario ladder: years to elimination in the median herd, one lever changed per row |
| `figs/fig16_interval_by_duration.png` | Revaccination interval against duration of immunity |

## Other figures

| File | Content |
| --- | --- |
| `fig1`, `fig1b`, `fig2` | One-at-a-time sweeps of the four parameters: time to elimination, R_v, population outcomes |
| `fig3`, `fig4` | Duration by coverage and direct by indirect efficacy heatmaps |
| `fig5`, `fig6`, `fig7` | PRCC, Sobol indices, Latin hypercube scatter |

| `fig9`, `fig10`, `fig11` | Duration of protection under annual campaigns; protected fraction; stochastic check |

## Tables

`tables/` holds the values behind every figure, named after the script that
wrote them (`oat_*`, `prcc`, `sobol`, `lhs_samples`, `stochastic_*`,
`revacc_*`, `onset*`, `memo_scenarios`, `tiles_booster_schedule`). Times are
years to herd prevalence below 0.1 percent; `Inf` means never.
